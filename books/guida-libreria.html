Guida Ufficiale

Come Configurare la Tua Biblioteca

Istruzioni per inserire i file HTML nella cartella e renderli visibili a tutti i visitatori del sito

✨ Struttura Condivisa per Tutti: I file inseriti nella cartella public/books/ dell'applicazione sono disponibili via web per chiunque apra questa homepage!

📁 1. Dove posizionare i file HTML

All'interno della cartella principale del progetto, trovi la cartella dedicata public/books/:

cartella-progetto/
├── public/
│   └── books/
│       ├── catalog.json                  ← Indice di tutti i libri del sito
│       ├── guida-libreria.html
│       ├── il-piccolo-principe.html
│       ├── il-mio-libro-1.html           ← Inserisci qui i tuoi file .html
│       └── un-altro-libro.html
└── src/

⚙️ 2. Come registrare un nuovo libro

Puoi registrare un nuovo libro in due modi semplicissimi:

  1. Dal pannello dell'app: Clicca sul pulsante in alto "📂 Gestisci File & Catalogo" oppure "Aggiungi Libro HTML", inserisci il nome del file (es. /books/il-mio-libro.html), titolo, autore e copertina.
  2. Modificando direttamente public/books/catalog.json: Aggiungi una voce come questa:
{
  "id": "il-mio-libro",
  "title": "Il Titolo del Tuo Libro",
  "author": "Nome Autore",
  "originalYear": 2026,
  "genre": "Avventura",
  "coverColor": "#1e3a8a",
  "coverPattern": "vintage-gold",
  "pagesCount": 120,
  "readingTime": "30 min",
  "rating": 5.0,
  "tags": ["Romanzo", "Nuovo"],
  "description": "Una breve sinossi visibile nella scheda del libro.",
  "htmlPath": "/books/il-mio-libro.html"
}

🎨 3. Funzionalità integrate nei tuoi file HTML

I tuoi file HTML possono contenere stili CSS personalizzati, JavaScript, immagini, animazioni e persino giochi o quiz interattivi!

🗑️ 4. Eliminare o Sostituire i Libri di Prova

Nella barra in alto della homepage puoi cliccare su "Gestisci File & Catalogo" per eliminare con un clic tutti i libri che non ti servono, lasciando solo i tuoi volumi preferiti.
